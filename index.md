# Manhua Factory

Manhua Factory is a private publishing tool run by Local Factories. It uploads videos that we make ourselves to our own YouTube channels, Shadow Manhua and Faris Fun Storytime, and sets their thumbnails, subtitles, playlists and publishing times.

It is not offered to the public: only the channel owner signs in to it.
